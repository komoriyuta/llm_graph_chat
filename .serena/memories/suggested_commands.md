# Suggested Commands
- `flutter pub get` — install/update Dart and Flutter dependencies.
- `flutter pub run build_runner build --delete-conflicting-outputs` — regenerate json_serializable models after schema changes.
- `flutter run -d chrome` / `flutter run -d macos` (or another device id) — launch the app for web or desktop testing.
- `flutter test` — execute Flutter/Dart test suite.
- `flutter analyze` — run static analysis with project lints.
- `dart format lib test` — apply Dart formatter to source and tests.
- `flutter build web` — produce a release web build for deployment.
- `flutter clean` — reset build artifacts if tooling behaves unexpectedly.
- `flutter pub run build_runner watch --delete-conflicting-outputs` — keep generated files in sync during development.
